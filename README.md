## General Reverse Image Search Engine

This project implements a general reverse image search engine capable of retrieving visually similar images from a dataset based on a given query image. The system leverages deep learning-based feature embeddings to represent images in a high-dimensional space, enabling effective similarity matching.

The engine is domain-agnostic, meaning it can operate across different types of image datasets without being restricted to specific applications, such as medical imaging or industrial inspection.

### Dataset

This project uses the Caltech101 dataset, which contains more thab 9000 images across 101 categories. Its diversity allows the engine to perform effectively across multiple object classes.
